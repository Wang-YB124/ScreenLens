# 屏译 ScreenLens 1.1.5

## 本次修改

- 设置页文案与 1.1.4 的 API Key 手动保存行为保持一致：
  - 设置页顶部改为「除 API Key 外，更改会自动保存；API Key 修改后点「保存」生效」。
  - 隐私说明改为「API Key 默认隐藏，可用眼睛按钮查看」，不再写“不会显示在界面上”。
  - 使用说明补充：填写新 Key 后必须点「保存」；不点保存保留原 Key。
- 功能与 1.1.4 相同：Key 输入只是草稿，失焦/切标签/等待都不会自动保存；「保存」按钮为空时禁用；「清除」仍需两次确认。
