屏译 ScreenLens 1.1.0 第三方组件与服务声明
==========================================

一、运行时与界面组件
--------------------
1. Electron / Chromium
   - 用途：桌面应用运行时与界面渲染。
   - 许可：Electron MIT；Chromium 及其依赖的许可证。
   - 完整许可见程序目录的 LICENSE 与 LICENSES.chromium.html。

2. KaTeX 0.19.1
   - 用途：数学公式 LaTeX 渲染。
   - 许可：MIT。
   - 完整许可：licenses/katex-LICENSE.txt。
   - 字体文件随 KaTeX 分发，许可同上。

3. highlight.js 11.11.1
   - 用途：代码块语法高亮。
   - 许可：BSD-3-Clause。
   - 完整许可：licenses/highlightjs-LICENSE.txt。

4. 图标与界面
   - 由 ScreenLens 项目制作。
   - 未使用第三方商业图标库。

二、服务
--------
1. 免费翻译（微软 Bing 翻译 / MyMemory）
   - 优先调用微软 Bing 翻译的公开网页接口；请求失败时自动回退 MyMemory。
   - 按需发送选中文字；两者均由第三方提供，受其额度、可用性与服务条款约束。
   - https://www.bing.com/translator
   - https://mymemory.translated.net/

2. Windows OCR
   - 由 Microsoft Windows 在本机提供，不需要上传截图。
   - 可用语言取决于系统安装的 OCR 语言包。

3. AI 服务商（用户自行配置）
   - 包括但不限于 DeepSeek、阿里云通义千问、Moonshot、智谱、SiliconFlow、OpenAI、Ollama。
   - 由用户提供服务地址、模型与 API Key。
   - 数据发送、计费与隐私规则由对应服务商决定。

三、其他
--------
- 本程序不包含 Youdao 或其他未授权词典接口。
- 本程序不包含统计埋点、广告 SDK 或遥测组件。
- 若再分发本发布包，请保留本声明、LICENSE、licenses 目录与
  Electron 的许可证文件。

四、免责声明
------------
本软件按“现状”提供，不附带任何明示或暗示担保。
AI 与第三方翻译服务的输出可能不准确；使用者需自行核对并承担使用风险。
具体责任限制以《许可证.txt》为准。

五、音频字幕（本地 Whisper）
----------------------------
1. whisper.cpp
   - 用途：本地语音识别运行程序（whisper-cli）。
   - 许可：MIT。
   - 完整许可：licenses/whisper.cpp-LICENSE.txt。
2. OpenAI Whisper ggml 模型（base/small q5_1）
   - 用途：本地中文/英文语音识别模型。
   - 许可：MIT（模型权重随 OpenAI Whisper 发布）。
   - 完整许可：licenses/Whisper-model-LICENSE.txt。
3. OpenCC 繁简转换字表
   - 用途：把 Whisper 可能输出的繁体字转换为简体。
   - 许可：Apache-2.0。
   - 完整许可：licenses/OpenCC-LICENSE.txt。

说明：音频字幕的识别完全在本机运行，音频不会上传；系统声音回环使用 Electron 38/Chromium 的 display-media loopback（audio:'loopback'），屏幕视频轨在开始后立即停止；字幕翻译仍使用免费翻译通道或已配置的 AI 模型，识别出的文字会按翻译链路发送。Windows 输出设备的静音/音量查询仅在本机通过 Core Audio 完成。
