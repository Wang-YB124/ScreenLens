屏译 ScreenLens 1.1.0 · 使用说明
================================

框选屏幕上的任意内容，立即翻译，或让 AI 解释代码、数学公式与科普文章。
Windows 原生 OCR 在本机完成，截图默认不离开电脑。


一、启动
--------
1. 解压发布包，双击 ScreenLens.exe。
2. 首次启动会显示新手引导。
3. 程序常驻系统托盘；关闭主界面会隐藏到托盘，并移除任务栏上无效的按钮。
4. 应用为单实例：再次点击任务栏固定图标、重新运行 exe 或点托盘图标会唤起已有主界面，不会启动第二个实例。
   主界面最小化时点击任务栏按钮可正常恢复；主界面不会强制置顶。

系统要求
- Windows 10 / 11 x64
- 至少安装一种 Windows OCR 语言包：简体中文或英文
- 免费翻译、AI 翻译与解释需要联网
- 约 300 MB 磁盘空间（便携版，无需安装 Node/Python）


二、快捷键
----------
- Ctrl + Alt + Q：框选翻译 / 解释
- Ctrl + Alt + R：开启 / 停止实时字幕

快捷键可在「设置 → 快捷键」中修改。
如果某个组合被其他程序占用，程序会自动换用备用组合，并在设置页提示。
默认使用 Ctrl+Alt+Q，是因为部分电脑上的 Ctrl+Alt+X 已被其他软件占用。


三、框选翻译与解释
------------------
1. 按 Ctrl+Alt+Q，主界面会自动收起，屏幕暂停并进入框选，给选区腾出空间。
2. 主界面收起后会稍等约 0.16 秒再冻结画面（避免把主界面截进去），随后拖拽框住要识别的内容，松开鼠标；取消框选或关闭结果窗后，主界面会恢复。
3. 结果浮窗会出现在选区旁边：
   - 「译文」：默认翻译成中文；内容已是中文时自动译为英文。
   - 「解释」：由 AI 生成结构化解释，需要先配置模型。
   - 「相关」：根据原文、译文和内容类型提取搜索关键词，并提供维基百科、必应/百度、Google Scholar、Stack Overflow/GitHub、PubMed 等搜索链接；点击用系统默认浏览器打开。
   - 可复制、重译、置顶；Esc 关闭。
4. 结果窗右上角的「内容类型」下拉可切换：自动 / 通用 / 代码 / 数学 / 科普。
   - 代码：保留代码语法，只翻译注释与用户可见文字；解释会指出语言、逻辑与风险。若真实模型把 OCR 压平的 Python 行合并成一行，程序会恢复 `def`/`return` 的合法缩进；复杂代码仍建议开启读图或人工核对。
   - 数学：公式以 LaTeX 渲染，解释符号、假设与推导直觉。
   - 科普：术语更准确，区分事实、模型与假说。
   - 自动：根据识别到的文字判断；判断不准时可手动切换。
   - 如果结果窗提示「识别可能不完整」，说明 Windows OCR 对公式/代码的符号或缩进识别不准。
     点提示里的「开启读图」可让 AI 直接看选区截图并重译（需模型支持视觉；截图会发送给该模型服务）。
5. 目标语言与解释语言现在与实时字幕使用同一组选项：简体中文、English、日本語、한국어、Русский、Français、Deutsch、Español、Português、Italiano。
   可在首页「目标语言」、设置 → 翻译，或结果窗顶部的「译为」下拉中切换；结果窗切换后立即重译，并同步保存到首页与设置，下一次截图沿用。免费翻译与 AI 翻译均支持这些目标语言。
6. 「相关」页的关键词可点击复制，或用「复制全部」一次复制；搜索链接会跳转到外部站点，结果与可用性由站点和当前网络决定。AI 翻译时关键词优先由 AI 提取；免费翻译或 AI 关键词失败时使用本地规则，不会因为这一点额外发送内容。


四、实时字幕
------------
1. 按 Ctrl+Alt+R 后，有两种方式选择识别范围：
   - 拖拽框选视频字幕、直播或滚动文字区域；
   - 或直接单击某个窗口（鼠标悬停会高亮窗口标题与识别区域），持续识别该窗口内容，并自动跟随窗口移动/缩放。
2. 字幕条会浮在选区下方（全屏选区/窗口时默认贴在屏幕底部）；文字区域点击穿透，不挡操作。
3. 画面文字变化时会自动重新识别并翻译；相同内容会复用缓存。
4. 再次按 Ctrl+Alt+R 停止。
5. 字幕条顶部整条区域都可以按住拖动来移动字幕（左上角的两列小圆点只是提示位置），不必只抓小圆点。
6. 字幕条右下角有缩放把手（三条斜线），按住拖动可调整字幕框的宽高；松开后自动保存，下次打开沿用。
   - 双击缩放把手可恢复自动大小；也可以点字幕条顶部新出现的圆形箭头按钮，或在齿轮设置面板底部点「恢复自动大小」。
   - 自动大小会随字号和译文行数增高；手动调整后就固定为您设置的尺寸，译文超出时按可用行数显示。
   - 即使把框调得很小，顶部控制按钮（自动大小、齿轮、×）也保持可见，便于恢复。
7. 字幕条右上方：
   - 齿轮：打开字幕设置，可调字号（14–40）、背景不透明度（35%–100%）、原文语言与译文语言；设置自动保存并立即生效。
   - ×：关闭实时字幕（带淡出效果，等同于停止）。
8. 设置 → 实时字幕 可调整引擎、刷新间隔、字号、行数与不透明度。

语言可任意组合：原文支持「自动」及中文、English、日本語、한국어、Русский、Français、Deutsch、Español、Português、Italiano；
译文支持「跟随设置」及上述语言。选择「跟随设置」时使用全局目标语言（中英互译时自动换向）；
选定具体译文语言后，即使原文与译文相同也按所选语言输出。
顶部控制条（含齿轮、×）可点击；字幕文字区域保持点击穿透，不影响下方窗口操作。

字幕条位于独立显示层，不会出现在系统截图/录屏中，也不会被 OCR 捕获，因此识别永远不会读到自己的字幕
（用它录制屏幕时同样不会录到字幕）。
窗口模式识别的是窗口客户区，可能包含网页标签栏、播放器控件等；需要更精准时仍可拖拽框选一小块区域。
窗口最小化时会提示，恢复后自动继续；目标窗口关闭后会自动停止字幕。

实时字幕是「选择一次识别范围，之后持续识别」：不需要每次重新选择，直到再次按快捷键停止。
启动实时字幕时主界面会自动收起，给识别区域腾出空间；取消框选、启动失败（例如 OCR/翻译引擎不可用）或停止字幕后自动恢复。字幕条会强制置顶，并可持续保持在其他置顶窗口之上；翻译加载时保留上一条字幕，避免频繁闪成“翻译中…”。
框选界面现在通常约 0.2–0.5 秒出现（冷启动首次略慢）；实时字幕会先按约 8 行/800 字截取最新内容再翻译，减少长窗口的等待。
免费翻译通道约 1 秒/句；需要更流畅的字幕时，建议在设置中配置 AI 模型（实时引擎默认自动选择 AI）。


五、配置 AI 模型（解释功能必需）
--------------------------------
设置 → AI 模型：
1. 选择服务商预设（DeepSeek、通义千问、通义千问 VL、Kimi、智谱、SiliconFlow、OpenAI、Ollama、自定义）。
2. 填写模型名称与接口地址（OpenAI 兼容的 /chat/completions）。
3. 填写 API Key；本地 Ollama 可留空。
4. 点「测试连接」确认可用。

说明：
- API Key 使用 Windows 凭据加密保存在本机，不会显示在界面上。
- 翻译可先用免费通道；解释必须配置 AI。
- 不配置模型时，「解释」页会显示配置入口，不会伪造解释。
- 选择 AI 翻译后，选中的文字会发送给你配置的模型服务。

多模态读图（可选）
- 在 AI 模型卡片开启「多模态读图」。
- 需要模型支持图片输入，例如 qwen-vl-max、gpt-4o、glm-4v 等。
- 开启后，一次框选的截图会发送给模型，公式、图表与代码通常更准确。
- 不支持视觉的模型会自动回退到纯文本模式。
- 实时字幕不使用读图，避免持续发送截图与额外费用。
- 公式、代码、图表建议开启读图；Windows OCR 对复杂公式和代码符号的识别有限。


六、隐私与数据
--------------
- 截图、OCR 与音频字幕：在本机完成；系统声音回环视频轨立即停止，音频不上传。
- 发送到外部的内容：
  - 使用免费翻译时，选中的文字发送给微软 Bing 翻译；Bing 不可用时回退 MyMemory。
  - 使用 AI 翻译/解释时，选中的文字发送给你配置的模型服务。
  - 开启多模态读图时，选中的截图也会发送给该模型服务。
- 不发送：整个桌面、其他窗口、历史记录、未选中的内容。
- 历史记录、截图和设置保存在：
  %APPDATA%\ScreenLens
- 可以在设置中暂停记录、清空历史，或直接删除上述目录。
- 本程序不包含统计埋点、遥测或自动更新回传。

第三方服务的可用性、额度与条款由其提供方决定；商业发布前请阅读发布包中的
《隐私说明.txt》与《第三方声明.txt》。


七、常见问题
------------
1. Windows 提示“已保护你的电脑”
   发布包未做代码签名。点“更多信息”，再点“仍要运行”。
   如用于正式商业发行，建议购买代码签名证书并对 exe 签名。

2. 提示没有可用的 OCR 语言包
   设置 → 时间和语言 → 语言和区域，安装简体中文或英文语言包，并确认其 OCR 组件可用。

3. 免费翻译失败
   微软 Bing 通道或备用 MyMemory 可能限流、无法连接或接口调整。可在设置中关闭免费通道并配置 AI 模型；
   或在“翻译引擎”中选择 AI。

4. 解释页一直提示配置模型
   解释功能只使用 AI，不提供词典兜底。请在设置中配置模型并测试连接。

5. 快捷键没反应
   可能被游戏、输入法或其他工具占用。设置页会提示并自动换用备用组合；

6. 主界面总是挡住其他窗口吗？
   不会。主界面已取消强制置顶和整窗悬停抢焦点，只会在鼠标移到按钮等控件上时尝试聚焦，方便一次点中。
   也可以手动改成其他组合。

6. 实时字幕有延迟
   AI 翻译需要网络往返。可把“刷新间隔”调大、选择更快的模型，
   或在实时字幕设置中使用免费通道。

7. 多模态读图报错
   当前模型可能不支持图片输入。关闭读图后会回退纯文本；
   也可以换用支持视觉的模型。

8. 想彻底卸载
   托盘右键退出，删除 ScreenLens 文件夹；
   如需清除数据，再删除 %APPDATA%\ScreenLens。

9. 公式/代码识别乱码
   - 尽量框大一点，包含完整的公式或代码；
   - 结果窗提示“识别可能不完整”时点“开启读图”；
   - 或在设置中开启多模态读图并配置视觉模型（qwen-vl-max、gpt-4o、glm-4v 等）。
   这是 Windows OCR 的固有弱项，AI 读图通常明显更准。

九、按钮与错误恢复（补充）
----------------------------
- 「截屏翻译」「实时字幕」点击后会立即变为「准备中… / 框选中… / 启动中…」并禁用，防止重复点击；框选窗口出现后即可继续操作。
- 从其他窗口切回 ScreenLens 时，先把鼠标在按钮上停留约 0.3 秒再点击，可避免第一次点击只用于激活窗口。
- 实时字幕框选中若按 Esc/右键取消，按钮会自动恢复，不会卡在「启动中」。
- 侧边栏显示「OCR 不可用」时，点下方的「重试 OCR」即可重新启动本地识别引擎。
- 免费翻译提示「已限流」或「无法连接」时，请稍后重试，或在设置→AI 模型中配置模型；AI 服务提示无法连接时检查网络/接口地址。


十、音频字幕（本地 Whisper）
----------------------------
1. 首页点「音频字幕」，或托盘菜单「音频字幕（系统声音）」；再次点击/点字幕 × 停止。
   启动时主界面会自动收起；停止、启动失败或取消时恢复。若主界面原本已被你最小化/收进托盘，程序不会强行弹出。
2. 默认采集系统声音（Windows 回环），也可在 设置 → 音频字幕 中切换为麦克风。
   系统声音使用 Electron 38 的 getDisplayMedia + audio:'loopback' 路径，屏幕视频轨会立即停止，只保留音频；
   若当前系统不支持回环，会明确提示改用麦克风。
3. 识别在本机由 Whisper 完成，音频不会上传。默认「极速」：0.9 秒首块 + 2 秒窗口/1 秒重叠，首条约 2 秒出现、连续语音约 1 秒更新一次，文本更碎；可切「均衡」（1.5 秒首块 + 2.5 秒窗口/1.2 秒重叠，首条约 2.6 秒、约 1.3 秒更新）或「准确」（small 模型，2 秒首块 + 3 秒窗口/1.5 秒重叠，首条约 3.8 秒、约 1.5 秒更新，文本更完整）。模型在本次音频会话内常驻；短窗不传 Whisper 提示词，避免复读。
   启动阶段实测（打包版）：字幕窗约 0.1–0.2 秒可见，进入聆听约 0.7–0.9 秒，首个分块约 1.7–1.8 秒，服务端识别约 0.25 秒，首条文字约 2.0 秒。
   没有声音时不会静默：会区分“当前没有播放声音”“输出已静音/音量为 0”“没有可用输出设备”“系统不支持回环/采集权限失败”，并在字幕条或通知中给出提示。
   播放中切换默认输出设备会自动重连；如果自动重连失败，会提示重新开启音频字幕。
4. 识别语言支持中文、English、日本語、한국어、Русский、Français、Deutsch、Español、Português、Italiano 与自动检测；
   可在 设置 → 音频字幕 或字幕条设置面板的「原文语言」中切换。自动检测会在首个有语音的分块锁定语言，之后沿用。
   字幕译文跟随全局目标语言/字幕设置；识别语言与目标语言相同时显示原文（ORIG），不同时自动翻译（免费或已配置的 AI 模型）。
5. 音频字幕条同样可拖动、缩放、调字号/透明度；× 停止，等同于再次点「音频字幕」。
   每次停止后会自动把原文/译文/时间、来源、识别/译文语言、模型和识别模式保存为 TXT，默认在 %APPDATA%\ScreenLens\audio-records；可在 设置 → 音频字幕 更改记录位置、恢复默认或打开文件夹，也可点字幕条上的文件按钮打开最近一条记录。
6. 设置 → 音频字幕：音频来源、识别模式（极速/均衡/准确）、识别语言（10 种 + 自动）、记录位置与本地模型状态。切换音频来源或识别模式后请重新开启音频字幕；
   切换默认输出设备后无需重开（会自动重连），若提示重连失败再重开。
7. 识别质量受模型、音量、噪声、口音影响；歌曲/多人同时说话可能需要人工核对。发布包已内置 Whisper base（约 57 MB）与 small（约 180 MB）及 whisper.cpp 运行时；重新获取模型可运行 scripts/fetch-whisper.ps1。
8. 隐私：音频只在本机识别；字幕翻译时识别出的文字会按免费/AI 翻译链路发送给对应服务。
