屏译 ScreenLens 1.1.0 · 使用说明
================================

框选屏幕上的任意内容，立即翻译，或让 AI 解释代码、数学公式与科普文章。
Windows 原生 OCR 在本机完成，截图默认不离开电脑。


一、启动
--------
1. 解压发布包，双击 ScreenLens.exe。
2. 首次启动会显示新手引导。
3. 程序常驻系统托盘；关闭主界面只是隐藏到托盘。

系统要求
- Windows 10 / 11 x64
- 至少安装一种 Windows OCR 语言包：简体中文或英文
- 免费翻译、AI 翻译与解释需要联网
- 约 300 MB 磁盘空间（便携版，无需安装 Node/Python）


二、快捷键
----------
- Ctrl + Alt + Q：框选翻译 / 解释
- Ctrl + Alt + R：开启 / 停止实时字幕

快捷键可在「设置 → 快捷键」中修改。
如果某个组合被其他程序占用，程序会自动换用备用组合，并在设置页提示。
默认使用 Ctrl+Alt+Q，是因为部分电脑上的 Ctrl+Alt+X 已被其他软件占用。


三、框选翻译与解释
------------------
1. 按 Ctrl+Alt+Q，屏幕会暂停并进入框选。
2. 拖拽框住要识别的内容，松开鼠标。
3. 结果浮窗会出现在选区旁边：
   - 「译文」：默认翻译成中文；内容已是中文时自动译为英文。
   - 「解释」：由 AI 生成结构化解释，需要先配置模型。
   - 「相关」：根据原文、译文和内容类型提取搜索关键词，并提供维基百科、必应/百度、Google Scholar、Stack Overflow/GitHub、PubMed 等搜索链接；点击用系统默认浏览器打开。
   - 可复制、重译、置顶；Esc 关闭。
4. 结果窗右上角的「内容类型」下拉可切换：自动 / 通用 / 代码 / 数学 / 科普。
   - 代码：保留代码语法，只翻译注释与用户可见文字；解释会指出语言、逻辑与风险。若真实模型把 OCR 压平的 Python 行合并成一行，程序会恢复 `def`/`return` 的合法缩进；复杂代码仍建议开启读图或人工核对。
   - 数学：公式以 LaTeX 渲染，解释符号、假设与推导直觉。
   - 科普：术语更准确，区分事实、模型与假说。
   - 自动：根据识别到的文字判断；判断不准时可手动切换。
   - 如果结果窗提示「识别可能不完整」，说明 Windows OCR 对公式/代码的符号或缩进识别不准。
     点提示里的「开启读图」可让 AI 直接看选区截图并重译（需模型支持视觉；截图会发送给该模型服务）。
5. 「相关」页的关键词可点击复制，或用「复制全部」一次复制；搜索链接会跳转到外部站点，结果与可用性由站点和当前网络决定。AI 翻译时关键词优先由 AI 提取；免费翻译或 AI 关键词失败时使用本地规则，不会因为这一点额外发送内容。


四、实时字幕
------------
1. 按 Ctrl+Alt+R，框选视频字幕、直播或滚动文字区域。
2. 字幕条会浮在选区下方，点击穿透，不挡操作。
3. 画面文字变化时会自动重新识别并翻译；相同内容会复用缓存。
4. 再次按 Ctrl+Alt+R 停止。
5. 设置 → 实时字幕 可调整引擎、刷新间隔、字号、行数与不透明度。

实时字幕默认「自动」：配置了 AI 模型就用 AI 翻译，否则用免费通道。
如果 AI 请求失败，会自动切换到免费通道并提示一次。


五、配置 AI 模型（解释功能必需）
--------------------------------
设置 → AI 模型：
1. 选择服务商预设（DeepSeek、通义千问、通义千问 VL、Kimi、智谱、SiliconFlow、OpenAI、Ollama、自定义）。
2. 填写模型名称与接口地址（OpenAI 兼容的 /chat/completions）。
3. 填写 API Key；本地 Ollama 可留空。
4. 点「测试连接」确认可用。

说明：
- API Key 使用 Windows 凭据加密保存在本机，不会显示在界面上。
- 翻译可先用免费通道；解释必须配置 AI。
- 不配置模型时，「解释」页会显示配置入口，不会伪造解释。
- 选择 AI 翻译后，选中的文字会发送给你配置的模型服务。

多模态读图（可选）
- 在 AI 模型卡片开启「多模态读图」。
- 需要模型支持图片输入，例如 qwen-vl-max、gpt-4o、glm-4v 等。
- 开启后，一次框选的截图会发送给模型，公式、图表与代码通常更准确。
- 不支持视觉的模型会自动回退到纯文本模式。
- 实时字幕不使用读图，避免持续发送截图与额外费用。
- 公式、代码、图表建议开启读图；Windows OCR 对复杂公式和代码符号的识别有限。


六、隐私与数据
--------------
- 截图与 OCR：在本机完成。
- 发送到外部的内容：
  - 使用免费翻译时，选中的文字发送给 MyMemory。
  - 使用 AI 翻译/解释时，选中的文字发送给你配置的模型服务。
  - 开启多模态读图时，选中的截图也会发送给该模型服务。
- 不发送：整个桌面、其他窗口、历史记录、未选中的内容。
- 历史记录、截图和设置保存在：
  %APPDATA%\ScreenLens
- 可以在设置中暂停记录、清空历史，或直接删除上述目录。
- 本程序不包含统计埋点、遥测或自动更新回传。

第三方服务的可用性、额度与条款由其提供方决定；商业发布前请阅读发布包中的
《隐私说明.txt》与《第三方声明.txt》。


七、常见问题
------------
1. Windows 提示“已保护你的电脑”
   发布包未做代码签名。点“更多信息”，再点“仍要运行”。
   如用于正式商业发行，建议购买代码签名证书并对 exe 签名。

2. 提示没有可用的 OCR 语言包
   设置 → 时间和语言 → 语言和区域，安装简体中文或英文语言包，并确认其 OCR 组件可用。

3. 免费翻译失败
   MyMemory 可能限流或无法连接。可在设置中关闭免费通道并配置 AI 模型；
   或在“翻译引擎”中选择 AI。

4. 解释页一直提示配置模型
   解释功能只使用 AI，不提供词典兜底。请在设置中配置模型并测试连接。

5. 快捷键没反应
   可能被游戏、输入法或其他工具占用。设置页会提示并自动换用备用组合；
   也可以手动改成其他组合。

6. 实时字幕有延迟
   AI 翻译需要网络往返。可把“刷新间隔”调大、选择更快的模型，
   或在实时字幕设置中使用免费通道。

7. 多模态读图报错
   当前模型可能不支持图片输入。关闭读图后会回退纯文本；
   也可以换用支持视觉的模型。

8. 想彻底卸载
   托盘右键退出，删除 ScreenLens 文件夹；
   如需清除数据，再删除 %APPDATA%\ScreenLens。

9. 公式/代码识别乱码
   - 尽量框大一点，包含完整的公式或代码；
   - 结果窗提示“识别可能不完整”时点“开启读图”；
   - 或在设置中开启多模态读图并配置视觉模型（qwen-vl-max、gpt-4o、glm-4v 等）。
   这是 Windows OCR 的固有弱项，AI 读图通常明显更准。
