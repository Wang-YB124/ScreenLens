# 屏译 ScreenLens 1.1.2

## 本次重点

1. **修复设置选项无法选择**：下拉框获得焦点后不再被主界面的悬停聚焦抢走；模式、语言、服务商等选项可以正常展开并保存。
2. **API Key 可以查看**：点击小眼睛会读取本机加密保存的 Key 并切换明文/掩码；点击「清除」会同时恢复掩码和占位提示。
3. **音频识别更准**：
   - 采集统一为 16 kHz，避免 48 kHz 直接线性降采样带来的混叠。
   - 在停顿处提前切块，减少把词切成「语音识 / 别技术」这类情况。
   - 均衡档改为 1.8 秒首块 + 3 秒窗口 / 1.5 秒重叠，首条约 2–3 秒、之后约 1.5 秒更新。
   - 新增「逐句」档：4 秒首块、最长 10 秒、1.2 秒重叠，按停顿成句，切词最少但延迟更高。
4. **体积明显减小**：压缩包由约 550 MB 降到约 330 MB，解压后约 579 MB。
   - SenseVoice 从 PyInstaller 子进程改为 sherpa-onnx-node 原生运行时（约 76 MB → 约 23 MB），启动更快，不再需要 Python。
   - 移除发布包中的 Whisper small（约 190 MB）与 OpenBLAS（约 51 MB）；中/英/日/韩使用 SenseVoice，其他语言回退 Whisper base，10 种语言能力不变。
   - 仅保留中/英常用 Electron 语言包（44 MB → 2 MB）。

## 音频识别实测（打包版，系统声音回环）

| 场景 | 首条字幕 | 识别引擎 | 说明 |
| --- | --- | --- | --- |
| 中文 · 均衡 | 约 2.4 秒 | SenseVoice，65–104 ms/块 | 采集 16 kHz；后续约 1.5 秒更新 |
| 中文 · 逐句 | 约 4 秒 | SenseVoice | 10 秒测试语音输出 7 个完整句子，无切词 |
| English · 快速 | 约 1.6 秒 | SenseVoice | 同上 |
| Français · 快速 | 约 1.6 秒 | Whisper base | 无 OpenBLAS 的 CPU 运行时，验证回退可用 |

逐句示例（同一段 10 秒中文测试音频）：

```text
人工智能正在改变我们的生活。
今天我们来聊一聊语音识别技术。
窗外的天气很好。
适合出去散步。
请把这段话完整的记录下来。
我们希望字幕能够尽快出现。
同时保持准确。
```

## 设置与记录

- 音频记录头部会记录实际引擎（SenseVoice / Whisper / 混合）和模式（极速 / 均衡 / 逐句）。
- 记录目录仍可在设置中更改、恢复默认或打开文件夹。
- 逐句模式不是默认档；需要更完整的句子时在 设置 → 音频字幕 → 识别模式 中选择，切换后重新开启音频字幕。

## 已知限制

- 逐句模式会等待停顿，首条约 4 秒、句间可能 2–4 秒，不适合追求最低延迟的场景。
- 其他语言（俄/法/德/西/葡/意）发布包只带 Whisper base；需要更高准确度可从源码构建时加入 small 模型。
- 识别质量仍受音量、噪声、口音、多人同时说话影响；音乐和歌曲建议人工核对。

## 兼容与安全

- Windows 10/11 x64，Electron 38.2.1，无需安装 Node/Python。
- API Key 仍使用 Windows DPAPI 加密保存；音频只在本机识别，不上传。
- 截图默认不会离开本机；只有选中的文字或开启读图后的选区截图会发送给配置的模型服务。
