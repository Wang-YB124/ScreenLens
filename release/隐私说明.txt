屏译 ScreenLens 数据处理与隐私说明
版本 1.2.0 · 2026-10-29

说明：本文描述 ScreenLens 1.2.0 的实际数据处理行为，不构成法律意见。


一、本机处理
------------
以下数据只在本机处理与保存：
- 你框选的屏幕截图。
- Windows OCR 识别出的文字。
- 翻译与解释结果、历史记录、设置。
- 音频字幕的系统声音/麦克风采集与本地识别结果（中/英/日/韩使用 SenseVoice，其余语言使用 Whisper；识别在本机完成，系统声音回环的屏幕视频轨立即停止，音频不上传）。
- 音频字幕记录：每次音频字幕停止后，自动把原文/译文/时间写入本机 TXT（也可从设置或字幕条打开记录目录）。
- 配置的 API Key（使用 Windows DPAPI 凭据加密保存）。

保存位置：%APPDATA%\ScreenLens（音频字幕记录默认在 %APPDATA%\ScreenLens\audio-records，可在设置中更改）
保存期限：历史记录默认最多 60 条，可在设置中调整、暂停记录或清空。
同一台电脑上的其他程序若能访问你的用户目录，也可能读取这些文件。


二、发送到外部服务的数据
------------------------
1. 免费翻译（微软 Bing 翻译 / MyMemory）
   - 触发条件：使用免费翻译通道（默认开启，可在设置中关闭）。
   - 通道顺序：优先使用微软 Bing 翻译的公开网页接口；不可用时自动回退 MyMemory。
   - 发送内容：选中区域的文字。
   - 不发送：截图、窗口标题、历史记录、设置。

2. AI 翻译与解释（你配置的模型服务）
   - 触发条件：配置并选择了 AI 翻译，或在结果窗点击“解释”。
   - 发送内容：选中区域的文字、目标语言、内容类型提示词；
     如果开启了“多模态读图”，还会发送选中区域的截图。
   - 相关知识关键词：使用 AI 翻译时，还会发送原文与译文用于提取搜索关键词；
     使用免费翻译、或 AI 关键词失败回退本地规则时，不会为此额外发送内容。
   - 不发送：完整桌面、其他窗口、历史记录、API Key 以外的设置。

3. 多模态读图（可选，默认关闭）
   - 开启后，选区截图会发送给你配置的视觉模型服务。
   - 实时字幕不使用读图，不会持续发送截图。
   - 点击实时字幕的「解释」时，当前字幕原文与译文会发送给所配置的模型服务；不发送截图。

4. 音频字幕（本地 SenseVoice 与 Whisper）
   - 系统声音通过 Electron/Chromium 的 display-media loopback 在本机采集；用于获取视频轨的屏幕内容不会被保存或上传，视频轨在开始后立即停止。
   - 麦克风来源通过系统 getUserMedia 在本机采集。
   - 音频本身不上传；仅识别出的文字按免费翻译/AI 翻译链路发送（与截图翻译相同）。
   - 输出设备静音/音量、默认设备名称仅在本机查询，用于提示，不上传。
   - 音频字幕记录只保存在本机；删除当前记录目录（默认 %APPDATA%\ScreenLens\audio-records）即可清除。

5. 不包含统计埋点、遥测、广告 SDK 或自动更新回传。


三、第三方服务
--------------
- 微软 Bing 翻译（公开网页接口）：免费翻译首选通道，受其服务条款与可用性约束。
  参考：https://www.bing.com/translator
- MyMemory：免费翻译备用通道，受其额度与服务条款约束。
  参考：https://mymemory.translated.net/
- Windows OCR：由 Microsoft Windows 在本机提供。
- AI 服务商：由你在设置中选择并配置，其隐私政策、数据保留与计费规则适用。
- 相关搜索链接：点击后由系统默认浏览器打开维基百科、必应、百度、Google Scholar、
  Stack Overflow、GitHub、PubMed、Wolfram Alpha 等站点；请求由浏览器直接发起，
  适用对应站点的隐私政策。
- Electron、KaTeX、highlight.js：界面与渲染组件，不参与数据处理。
  组件许可证见发布包 licenses 目录与 LICENSES.chromium.html。

本应用与微软 Bing 翻译、MyMemory、Microsoft、各 AI 服务商没有隶属或背书关系。


四、你的控制权
--------------
- 关闭免费翻译通道：设置 → 翻译 → 免费翻译通道。
- 关闭多模态读图：设置 → AI 模型 → 多模态读图。
- 暂停历史记录：设置 → 通用 → 暂停记录历史。
- 清空历史：设置 → 通用 → 清空历史；或删除 %APPDATA%\ScreenLens。
- 清除 API Key：设置 → AI 模型 → 清除。
- 卸载：托盘退出后删除程序目录；如需清除数据，删除 %APPDATA%\ScreenLens。

五、安全与限制
--------------
- API Key 使用 Windows 凭据加密；settings.json 中不保存明文 Key。
- 截图仅在开启多模态读图时离开本机。
- AI 输出可能不准确，重要场景请自行核对。
- 本程序不保证第三方翻译/模型服务持续可用，也不对其输出承担责任。
