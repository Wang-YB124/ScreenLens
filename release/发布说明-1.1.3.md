# 屏译 ScreenLens 1.1.3

## 本次修复

- **防止误删 API Key**：设置 → AI 模型 的「清除」改为二次确认。
  - 第一次点击只进入「确认清除」状态，4 秒内没有再次点击会自动恢复为「清除」。
  - 再次点击「确认清除」才会真正删除 Key。
  - 两次点击间隔小于 500 ms（例如快速双击）不会删除，避免手滑。
- **已保存状态更明确**：输入框占位提示改为「已保存 Key ••••尾号，点右侧眼睛查看，或输入新 Key 替换」，不再让人误以为 Key 丢了。
- 功能、识别与包内容与 1.1.2 相同；API Key 仍使用 Windows DPAPI 加密保存在本机。

## QA

- 隔离配置测试：保存测试 Key → 第一次点「清除」后 `hasKey=true`、按钮显示「确认清除」；等待 4 秒自动取消；再次点击并确认后 `hasKey=false`。
- 开发版与打包版均验证；测试未使用真实 Key，也未调用付费 AI。
