# 屏译 ScreenLens 1.1.1

发布日期：2026-10-28  
平台：Windows 10/11 x64（便携版）  
许可：MIT

## 本次更新

1. **本地音频识别升级为混合引擎**
   - 中/英/日/韩：本地 SenseVoice int8，模型只加载一次，常驻服务；识别通常 50–100ms。
   - 俄/法/德/西/葡/意：继续使用本地 Whisper（base/small），保留原 10 种语言能力。
   - 自动检测：首个有语音分块用 Whisper 锁定语言；检测为中/英/日/韩时，后续分块自动切换到 SenseVoice，其余语言继续 Whisper。
   - 识别失败时自动回退 Whisper；音频始终不上传。

2. **更快的首条字幕**
   - 极速模式中文实测：首块约 1.4 秒，首条字幕约 1.4–1.6 秒，识别约 45–50ms。
   - 均衡模式仍为默认，文本更完整；准确模式保留最大上下文。

3. **幻觉过滤**
   - 新增 `字幕by…`、`字幕由…`、`字幕制作…` 等字幕署名类 Whisper 幻觉过滤，避免静音/噪声时出现“字幕by李宗智”等无关文字。

4. **记录与隐私**
   - 音频记录头部标注实际引擎（SenseVoice / Whisper / 混合）。
   - SenseVoice 与 Whisper 均在本地运行；音频不上传。翻译/解释仍按原链路发送文字。

## 包体说明

发布包新增 SenseVoice int8 模型（约 229MB）及其常驻服务（约 76MB），并保留 Whisper base/small 作为其他语言回退，便携包约 550MB。GitHub Releases 单文件上限 2GB。

## 验证

- 中文：SenseVoice 识别整段 20.8s 语音文字完整；极速首条约 1.4–1.6 秒，约 1 秒更新。
- 英文：走 SenseVoice；法文：回退 Whisper；自动检测：首个 Whisper 分块后切换到 SenseVoice。
- 设置页显示“中/英/日/韩：SenseVoice · 其他语言：Whisper”，音频记录头部同步。
- 幻觉过滤单测覆盖 `字幕by李宗智`、`字幕由…`、`字幕制作…`、`谢谢观看` 等，不误伤正常句子。
