# 屏译 ScreenLens 1.1.4

## 本次修改

- **API Key 改为手动保存**：输入框只作为草稿，输入后不会自动写入，也不会因为失焦、切换标签页而保存。
- **新增「保存」按钮**：只有点击保存才会把新 Key 加密写入；不点保存时始终保留原来的 Key。
- 输入框为空时「保存」按钮禁用；保存成功后输入框清空，占位提示更新为新 Key 的尾号。
- 保留上一版的两步「清除」确认：第一次点击只进入「确认清除」，4 秒后自动取消，第二次点击才删除。
- 眼睛按钮仍可读取并显示已保存的 Key；关闭显示后草稿或已保存值不会自动提交。

## QA

- 隔离配置测试：
  - 输入草稿后等待 1.5 秒，`hasKey` 仍为 false，未写入。
  - 点「保存」后 `hasKey=true`，输入框清空，按钮恢复禁用。
  - 已有 Key 时输入第二个草稿，等待与切换标签页后仍读取到第一个 Key；点保存后才切换为第二个。
  - 清除仍需两次确认。
- 未使用真实 Key，也未调用付费 AI。
