# 屏译 ScreenLens 1.1.0

发布日期：2026-10-27  
平台：Windows 10/11 x64（便携版）  
许可：MIT

## 本次重点

1. **代码 / 数学 / 科普领域优化**
   - 自动识别内容类型，也可在结果窗手动切换。
   - 代码：保留语法与标识符，只翻译注释/可见文字，解释语言、逻辑和风险；若真实模型把 OCR 压平的 Python `def`/`return` 合并成一行，会自动恢复为合法缩进。
   - 数学：公式用 LaTeX 渲染（KaTeX），解释符号、假设与推导。
   - 科普：强调术语准确、单位与事实/假说边界。

2. **公式与代码渲染**
   - 结果窗和实时字幕支持 LaTeX。
   - 代码块高亮（highlight.js）、语言标签、一键复制。

3. **多模态读图（可选）**
   - 开启后把选区截图发送给视觉模型，公式、图表、代码更准确。
   - 不支持视觉的模型自动回退文本模式；实时字幕不发送截图。
   - 默认关闭；需在设置中显式开启。

4. **实时 AI 字幕**
   - 实时引擎默认“自动”：有 AI 模型用 AI，否则用免费通道。
   - 支持领域提示词，数学公式可在字幕中渲染。
   - AI 失败时自动回退免费通道并提示一次。
   - 字幕条强制置顶，可覆盖在游戏/视频等置顶窗口之上；翻译加载时保留上一条字幕，不再频繁清空。
   - OCR 暂时失败时显示可读的重试提示，不暴露 PowerShell 原始报错；免费模式启动时会提示延迟较高。
   - **可拖动 / 可缩放**：字幕条顶部整条控制带都可按住拖动（不再局限于左上角小把手）；右下角缩放把手可调整宽高，松开后自动保存并跨会话沿用。双击缩放把手、点顶部新增的圆形箭头按钮或设置面板中的「恢复自动大小」可恢复内容自适应。手动尺寸下译文按可用高度显示行数；即使框调小，顶部按钮也保持可见。
   - **按窗口识别**：选择识别范围时可直接单击某个窗口（悬停会高亮窗口与识别区域），持续识别该窗口客户区并自动跟随窗口移动/缩放；窗口最小化时提示、恢复后自动继续，窗口关闭后自动停止。仍可拖拽框选任意区域。
   - **独立显示层**：字幕窗不进入系统截图/录屏，也不会被 OCR 捕获，从根源上避免识别到自己显示的字幕。
   - **全屏位置**：全屏选区或全屏窗口时，字幕默认贴在屏幕底部；仍可拖动到任意位置。
   - **字幕内设置**：点击字幕条右上角齿轮打开设置面板，可实时调整字号（14–40）、背景不透明度（35%–100%）与翻译语言。
   - **语言对选择**：原文支持自动识别与中文、English、日本語、한국어、Русский、Français、Deutsch、Español、Português、Italiano；译文支持跟随全局设置或上述任意语言。选择具体译文语言时按所选语言输出，设置自动保存并在下一帧重新翻译。
   - **关闭效果**：点击右上角 × 停止字幕，并带淡出动画；不再需要记快捷键。
   - **点击穿透**：只有顶部控制条和展开的设置面板接收鼠标，字幕文字区域保持点击穿透；控制条会周期性置顶，避免被其他置顶窗口压住。
   - 设置面板内嵌字幕预览，调整字号/透明度时可直接查看效果；翻译语言切换会显示“正在重译”提示。

5. **发布可用性**
   - 首启新手引导。
   - 「关于与隐私」、第三方声明、免费通道开关。
   - 内容类型默认值、Qwen-VL 预设。
   - 多模态读图隐私提示。

6. **相关知识 / 外部链接搜索**
   - 结果窗新增「相关」页：根据原文、译文与内容类型提取搜索关键词，并提供外部搜索链接。
   - 站点按领域/主题选择：通用→维基百科 + 必应/百度；数学/科普→Google Scholar + 维基百科（数学额外提供 Wolfram Alpha）；代码→Stack Overflow + GitHub；历史人物→维基百科 + 必应；医疗→PubMed + 维基百科；新闻→Bing 新闻 + 维基百科；产品→必应 + 维基百科。
   - 关键词优先由 AI 提取；未配置模型、使用免费翻译或 AI 失败时自动回退本地规则。关键词可点击复制，也可一次复制全部。
   - 所有链接均为真实站点的搜索页，使用 `encodeURIComponent` 编码，不伪造或拼凑站点；点击通过系统默认浏览器打开。
   - 页面会标明关键词来源（AI 提取 / 本地提取）；AI 关键词失败时给出提示，不影响翻译、解释与读图链路。

## 行为变化

- 接口说明与解释不再使用未授权的第三方词典兜底；解释功能需要配置 AI 模型。
- 为了让用户在发布前能关闭第三方免费翻译，新增「免费翻译通道」开关（默认开启）。
- 默认快捷键仍为 `Ctrl+Alt+Q` / `Ctrl+Alt+R`；被占用时自动回退并提示。
- 现在默认优先使用 AI 翻译（配置了模型时），免费通道作为回退/无模型方案。

## 10 轮场景测试后的修正

在原 5 轮基础上新增 5 个场景（Python、微积分、物理、中文技术说明、英文长句），共 10 轮：英文、中文、JavaScript、几何、生物、Python、微积分、物理、中文技术、英文长句，10/10 通过。

- 增强物理自动领域识别：补充 Newton、acceleration、velocity、momentum、friction、wavelength、frequency、voltage、circuit、physics 及中文「牛顿/加速度/动量/摩擦/波长/频率/电压/电路/物理」等关键词；强科学信号优先于仅由单位/等号产生的弱公式信号。
- 修复 OCR 把 Python 压成一行后误判「通用」的问题：识别 `def name(...)` 签名并与 `return` 组合加权，代码场景仍进入代码提示词。
- 增强数学自动领域识别：即使 OCR 丢失 π/² 等符号，也能根据 circle、sphere、area、volume 等词识别为数学。
- 结果窗新增「识别可能不完整」提示：代码/数学内容可一键开启 AI 读图并重译；提示会明确告知截图会发送给模型。
- 免费翻译、代码高亮/复制、数学 KaTeX、科普解释均通过。
- 已确认的 OCR 弱项：Windows OCR 对代码符号（=>、括号）与数学公式（π、上下标）识别不稳定；中文个别字符可能被拆（例如“你”被拆成“亻尔”），免费翻译结果仍可正确。
- 建议：公式、代码、图表开启「多模态读图」并配置视觉模型；普通文本/免费翻译不受影响。

## 启动性能与主窗口收起（2026-10-27）

- **实时字幕也收起主界面**：点击/热键启动实时字幕后，在截图前先隐藏主界面；取消框选、引擎不可用、OCR 硬失败或停止字幕时自动恢复。截图翻译与实时字幕现在行为一致，且不会把主界面截进识别背景。
- **主界面即时消失**：按下截图/实时/音频按钮时先在首页同步淡出（不等 IPC），主进程随即 `setSkipTaskbar(true)` + `hide()`；启动兜底定时器、晚到的 `ready-to-show` 与悬停聚焦都不再在框选/字幕进行中把主界面拉回来。打包版冷启动实测：截图 9 ms 隐藏 / 220 ms overlay 可见，实时字幕 10 ms 隐藏 / 191 ms overlay 可见；取消或停止后恢复，原本最小化的主界面保持最小化。
- **框选启动提速**：
  - 截屏从 Electron `desktopCapturer` 全屏缩略图改为复用 OCR worker 的 GDI 截图（`CopyFromScreen`，只截取物理屏幕，worker 内完成 PNG 写入），实测 capture 从 1.2–3.3 秒降到约 0.08–0.18 秒。
  - 预览图从整屏 PNG `toDataURL`（约 1.6 MB 字符串）改为 1.25× DIP JPEG Buffer + `blob:` 解码；编码从 220–250 ms 降到约 20 ms。
  - 框选窗改为启动后预热、按显示器复用；首次预热的窗口直接复用，避免每次新建/加载。
  - 实时字幕的窗口枚举从“先串行枚举再截屏”改为截屏后补发窗口列表，不再阻塞 overlay 出现；主屏优先准备，其他屏随后加入。
- **实测（同一台 2560×1600 / 150% 机器，点击→overlay 首帧）**：
  - 截图：冷 3613 ms → 319 ms；热 1497 ms → 155–216 ms。
  - 实时字幕：overlay 3591 ms → 169 ms（热，预热复用）/ 319 ms（冷，窗口在本次创建）；首条字幕从 8.8–10.9 秒降到约 2.8 秒（短区域、缓存命中）或 1.7–3.8 秒（长窗口，800 字截断后）。
- **回归**：截图翻译、实时字幕、取消框选、结果窗关闭恢复、热键启动、窗口模式、引擎不可用恢复、免费翻译、Mock AI 翻译/解释/相关均通过；多显示器逻辑按每屏预热/创建 overlay 并处理显示器增删，但本机只有单屏，未做物理多屏实测。

## 音频字幕修复与启动优化（2026-10-27）

- **系统声音采集改为 Electron 38 现代路径**：旧版 `getUserMedia + chromeMediaSource:'desktop'` 在 Electron 38 上经常拿不到回环音频。现在主进程 `session.setDisplayMediaRequestHandler` 返回 `{ video: screenSource, audio: 'loopback' }`（`useSystemPicker:false`），捕获渲染进程用 `navigator.mediaDevices.getDisplayMedia({ audio:true, video:true })`，视频轨在开始后立即停止/移除，只保留 `System audio` 音频轨。实测音频轨 `deviceId=loopback`、48 kHz、单声道。
- **音频字幕启动收起主界面**：点击/托盘启动后先隐藏主界面，停止、启动失败、权限/回环不可用或采集错误时恢复；原本已最小化/收进托盘的主界面不会被强行弹出。与截图/实时字幕共用同一组回调。
- **启动阶段优化**：屏幕源在应用启动时预热并缓存（避免每次音频启动都等 `desktopCapturer.getSources` 数秒）；首个分块缩短为约 3 秒，之后恢复 6 秒分块。实测（点击→）：字幕窗 109–182 ms 可见，进入聆听 301–769 ms，首个分块 3.46–3.78 秒，Whisper 完成 5.19–6.81 秒；设备切换重连约 96 ms。
- **无声音不再静默**：最后一个分块静音时查询 Windows 默认输出端点（Core Audio，本机）：
  - 没有播放声音 → “正在聆听系统声音，但当前没有检测到播放声音”；
  - 输出静音/音量为 0 → “系统输出已静音或音量为 0”；
  - 没有可用输出设备 → 明确提示检查扬声器/耳机；
  - 不支持回环/权限失败 → 明确提示改用麦克风或检查权限。
- **输出设备切换**：捕获渲染进程监听 `devicechange`，自动重新建立 getDisplayMedia/loopback；失败时提示“输出设备已切换，自动重连失败；请重新开启音频字幕”。
- **验证**：本机实际播放中文 TTS（默认输出，音量 0.17），回环首块 RMS 0.054–0.143、活跃比例 0.10–0.67，Whisper 识别出“这是一段用于测试系统音频识别的中文语音。”；麦克风来源、无声音/静音提示、不支持回环提示、设备切换重连、主窗口恢复均通过。测试机后台持续有系统声音，静音场景的提示用捕获窗口注入 silence 状态并同时查询真实设备状态验证（真实回环 RMS/文字另行验证）。
- 已知限制：首个分块 3 秒 + Whisper 5–7 秒是本地识别的基本延迟；长句/噪声/多人说话可能识别不完整。多显示器/真实物理设备切换未在本机逐一实测。

## 已知限制

- 未做代码签名，Windows SmartScreen 可能提示；点“更多信息 → 仍要运行”。
- 免费翻译优先使用微软 Bing 翻译的公开网页接口，失败时回退 MyMemory；两者都可能限流或调整，商业发布前请评估其条款。
- AI 输出可能不准确；数学推导、代码风险与科普结论请自行核对。
- 多模态、AI 翻译与解释需要兼容的服务商和 API Key；已用 DeepSeek chat 验证文本翻译/解释/关键词链路，视觉读图仍需视觉模型 Key 验证。
- 音频字幕使用本地 Whisper；默认 base 实时模式，首个分块约 2 秒，之后约每 2 秒更新一次；可切 small 准确模式。识别延迟仍与音频长度/噪声/机器性能有关。
- 实时 AI 字幕的延迟取决于模型与网络，费用由所选服务商计费。
- Windows OCR 的可用语言取决于系统语言包；公式/代码符号识别有限，推荐使用 AI 读图。
- 相关链接指向外部搜索站点，搜索结果与站点可用性由服务方和当前网络决定；Wikipedia、Google Scholar 在部分网络可能不可达。
- 相关关键词由 AI 或本地规则提取，可能不完整；可复制关键词后自行搜索或结合原文判断。
- AI 质量取决于所选模型；流程回归主要使用本地 OpenAI 兼容 Mock，另用 DeepSeek chat 做了真实 10 轮相关知识与 Python 代码验证，其他服务商/模型未逐一评测。

## 主界面与翻译速度优化（2026-10-27）

- **主界面不再“常驻置顶”**：移除覆盖整窗的悬停抢焦点轮询；只有鼠标移到按钮、输入框等可操作控件上时才尝试聚焦，避免浏览其他窗口时被主界面反复顶到前面。
- **框选更宽敞**：开始框选前自动收起主界面（窗口被其他程序挡住时隐藏），等截图完成后再释放；取消框选或关闭结果窗后自动恢复主界面。系统截图与 OCR 不再读到主界面自身。
- **免费翻译更快**：免费通道改为优先调用微软 Bing 翻译的公开网页接口，MyMemory 作为备用；长文本按段并行并在首个分片返回时先显示译文，重复内容走 15 分钟本地缓存。实测短文本约 0.9–1.2 秒返回，之前 MyMemory 单独通道常见 3 秒以上并可能 429。
- 结果窗底部会显示实际通道（「微软翻译」或「免费翻译」）；实时/音频字幕的免费通道仍显示 FREE。

## 主界面即时收起与结果语言选择（2026-10-28）

- **主界面即时消失**：隐藏前 `setOpacity(0)`，绕过 Windows DWM 对隐藏窗口约 100 ms 的淡出；恢复时 `setOpacity(1)`。逐帧实测：点击后 30 ms 的屏幕帧里主界面已完全消失，不再出现半透明淡出；取消/停止后首页恢复完全不透明。
- **隐藏后等待片刻再冻结画面**：像系统截图工具一样，主界面/结果窗隐藏后等待 160 ms（`SL_HIDE_SETTLE_MS` 可调）再采集屏幕，确保冻结背景中没有任何主界面残影；overlay 约 0.33–0.42 s 出现，仍在 0.5 s 内。
- **结果窗直接切换译文语言**：结果窗顶部新增 10 种目标语言下拉（与首页/实时字幕一致），切换后立即重新翻译，并把选择同步保存到首页「目标语言」和设置，下一次截图沿用。
- **修复结果窗卡在“识别中…”**：结果窗页面加载较慢时，旧的 OCR 初始记录可能覆盖已完成译文；现在始终显示主进程最新记录，并忽略同一条记录从 done 回退到 ocr。
- **修复实时字幕无法再次启动**：在框选覆盖层仍打开时停止实时字幕，现在会取消框选；此前 `selecting` 残留导致下一次启动返回 busy。
- **修复中文排版判断**：结果窗读取正确的 `meta.targetLang`；中文/日文/韩文译文使用对应字体排版。
- **验证**：打包版连续 10 轮截图翻译并切换全部 10 种语言，10/10 通过；实时字幕收起/停止 2/2 通过。主界面隐藏 23–34 ms，稳定 160 ms 后 overlay 可见 333–420 ms，+1.7 s 仍保持隐藏；冻结画面逐张检查无主界面残影。数据见 `docs/qa/ten-round-2026-10-28.json`、`docs/qa/fade-2026-10-28.json`。

## 音频识别完善（2026-10-28）

- **10 种识别语言 + 自动检测**：音频字幕不再只支持中文/英文；新增日本語、한국어、Русский、Français、Deutsch、Español、Português、Italiano，以及「自动检测（首段锁定）」。每种语言使用对应的 Whisper 语言码和译文源语言标签；中文仍自动繁转简。
- **字幕条直接切换识别语言**：音频模式下字幕条设置里的「原文语言」现在修改音频识别语言（含自动），不再误改实时字幕设置；切换后对下一个分块生效，并保存到设置。
- **音频记录**：每次停止音频字幕时，自动把原文/译文/时间、来源、识别/译文语言、模型和识别模式保存为 UTF-8 TXT；设置 → 音频字幕 可更改/恢复记录目录并打开文件夹，字幕条上的文件按钮可打开最近一条记录。记录只保存在本机；默认目录为 `%APPDATA%\ScreenLens\audio-records`，可自定义。
- **实时化与识别模式**：新增常驻 `whisper-server.exe`（模型只加载一次，16 线程上限）和「识别模式」设置：极速为 0.9 秒首块 + 2 秒窗口/1 秒重叠，首条约 1.96–2.03 秒、连续语音约 1.02–1.06 秒一更（文本更碎）；均衡为 1.5 秒首块 + 2.5 秒窗口/1.2 秒重叠，首条约 2.60–2.94 秒、约 1.25–1.37 秒一更（更完整）；准确使用 small 模型，首条约 3.78 秒、约 1.45–1.78 秒一更，文本最完整。默认极速。
- **短窗不再传 Whisper 提示词**：中文静态提示词在 1–2 秒窗口下会偶发 200+ 字复读，英文提示词会被回显；去掉后中文仍由繁转简兜底。自动检测首窗用 1.5 秒 + `verbose_json` 检测一次，实测中文 2.84 秒出首条。
- **解码提速**：Whisper 增加 `-bo 1 -bs 1 -sns`，线程上限 16；服务端 1 秒块识别约 241–250 ms（base）。
- **验证**：打包版系统回环 + 本地 TTS 极速/均衡各 3 轮，首条 1.96–2.03 秒 / 2.60–2.94 秒；10 语言 + 自动检测、4 个 zh/en 显式/自动音频用例、字幕条语言联动 5/5；默认/自定义音频记录、静音/无声音提示、停止恢复主界面、单实例任务栏唤醒均通过。其他 8 种语言使用同一链路，但本机没有对应 TTS，未逐种录制真人语音。
- 数据见 `docs/qa/audio-speed-2026-10-28.json` 与 `docs/qa/audio-lang-2026-10-28.json`；全程免费翻译，未使用付费 AI 额度。

## 音频字幕（本地 Whisper）

- 新增「音频字幕」：采集 Windows 系统声音回环（可选麦克风），使用本地 whisper.cpp + 常驻 Whisper 服务识别，不需要联网或 API Key。默认为实时 base 模型，可切准确 small 模型。
- 默认极速模式：0.9 秒首块，首条约 2 秒出现，之后连续语音约每 1 秒更新一次（2 秒窗口、1 秒重叠）；可切均衡（首条约 2.6 秒、约 1.3 秒更新）或准确（small，首条约 3.8 秒、约 1.5 秒更新）。模型在音频会话内常驻，避免每块重复加载；自动繁体转简体，并过滤静音/括号音效等常见幻觉。短窗不传 Whisper 提示词，避免复读。
- 识别原文复用实时字幕的翻译链路：识别语言与目标语言相同时显示原文（ORIG），否则用免费或 AI 模型翻译；字幕条继续支持拖动、缩放、字号/透明度设置与 × 关闭。
- 音频只在本地识别，不上传；翻译时识别文字会发送给免费/AI 服务（与文本翻译相同）。
- 发布包内置 Whisper base（约 57 MB）与 small（约 180 MB）模型、whisper.cpp CLI/server 运行时；压缩包体积相应增大。重新获取模型可运行 scripts/fetch-whisper.ps1。
- 已验证：系统声音回环采集、中文/英文 TTS 端到端识别、Mock AI 流式翻译、关闭停止、字幕窗口拖动/缩放复用；识别质量受模型、音量、噪声与口音影响。
