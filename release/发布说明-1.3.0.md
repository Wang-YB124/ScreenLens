# 屏译 ScreenLens 1.3.0

## 代码字幕（新）

在 VS Code / Cursor / Qoder 中写作时，把当前文件实时暂存到字幕条，写完一段后自动解释并给出修正建议。

- 设置 → 实时字幕 → 字幕来源新增「VS Code 编辑器」。
- 配合发布包根目录的 `ScreenLens-Code-0.2.1.vsix`：安装后状态栏显示连接状态，扩展把当前活动文件的代码通过本机回环桥接传给 ScreenLens。
- 字幕条显示文件、光标附近代码、已暂存行数和待审阅字数；默认新增 20 行或 1200 字（任一达到）自动审阅，可在设置中调整。
- 审阅结果在字幕条内流式显示，包含代码块、风险与具体修正建议；可关闭「自动解释和修正建议」，改为点字幕条上的「审阅」手动触发。
- 大文件会截取光标附近的窗口（最多约 6 万字符），仍按整个文件行数显示；文件切换、删除代码后会重新计数。
- 代码只在本机应用与编辑器之间传递，停止字幕后桥接文件与内存快照立即清除，不写入历史；只有触发 AI 审阅时才发送给配置的模型。
- 桥接仅监听 127.0.0.1 随机端口，使用每次启动随机生成的 Bearer 令牌。

## 扩展

- ScreenLens Code 0.2.1：新增代码字幕桥接与输出面板连接日志；保留解释选中代码、diff 预览后手动应用修正、SecretStorage 保存 API Key。
- 扩展兼容 VS Code 1.80+、Cursor、Qoder。

## 界面

- 实时字幕设置按来源显示：编辑器模式隐藏翻译引擎、刷新间隔和译文行数，只保留代码阈值、自动审阅、字号和透明度。
- 代码字幕条隐藏原文/译文语言选择，使用等宽字体显示代码，解释中的 Markdown 代码块保留格式。
- 编辑器模式按钮显示「审阅」；翻译引擎标识显示 `LOCAL`，文件基名显示在顶部。

## 验证

- 代码字幕应用端到端 26/26：设置来源与阈值、桥接鉴权、代码暂存、无暂停连续输入触发审阅、代码块渲染、第二轮阈值、手动审阅、大文件行数与光标窗口、真实 VS Code 扩展上报、停止清理。
- 真实 VS Code 集成 6/6：安装 0.2.1 VSIX，打开工作区文件后自动上报，字幕条显示文件名、代码和「自动解释已关闭」。
- 扩展大文件窗口测试通过：3000 行文件在光标第 2500 行时发送 52,780 字符窗口，光标相对位置与总行数正确。
- 屏幕实时字幕回归通过；所有测试使用隔离 `--user-data-dir` 与本地 Mock AI，没有使用真实 Key 或付费额度。
