## 音频字幕（本地 Whisper，2026-10-27）

- 基础验证：Electron 桌面捕获可取得系统回环音轨（label=System Audio），播放中文 TTS 时 RMS 0.05–0.11；whisper.cpp BLAS + small-q5_1 对 10 秒中文音频识别约 0.7–1.6 秒。
- 端到端（开发版）：首页「音频字幕」→ 系统声音回环 → 本地 Whisper → 字幕条。中文 TTS 得到“这是一段用于特市系统音频识别的中文语音 / 今天天气很好我们一起来学习人工智能”（small 模型基本正确），显示“音频”徽标与 ORIG；静音/括号幻觉经过滤后不再出现；点字幕 × 关闭后音频状态与采集窗口均结束。
- 英文 TTS + 本地 Mock AI 翻译：识别出 “This is a test of real-time audio subtitles. / The system audio is captured locally and transcribed by whisper...” ，流式翻译显示 EN → 简体中文，provider=AI；关闭后恢复设置。
- 模型选择：优先 small-q5_1（约 182MB），base-q5_1 作为开发环境备用；发布包仅内置 small 以控制体积。
- 已知：约 6 秒分块带来 6–8 秒字幕延迟；识别受音量/噪声/口音影响；系统声音依赖 Windows 回环（已在本机验证），麦克风模式使用默认输入设备。
- 打包版（312MB 包）复测：内置 Whisper small q5_1 路径就绪；首页「音频字幕」标题/设置卡状态正确；系统声音中文 TTS 识别两段均正确（“这是一段用于测试系统音频识别的中文语音”“今天天气很好我们一起来学习人工智能”），字幕 × 关闭后音频结束；播放结束后曾出现一次“盐工技能”幻觉，已加入语音活跃比例门限（RMS≥0.0025 且活跃采样≥5%）后重打包复测。

## 主界面置顶、框选收起与免费翻译加速（2026-10-27）

## 主界面即时收起（2026-10-27）

- 数据：[hide-2026-10-27.json](hide-2026-10-27.json)。
- 问题：冷启动后开始截图/实时字幕时，主界面偶尔会先消失又出现；发布包里 `ready-to-show` 晚于收起动作时会无条件 `show()`，悬停聚焦的 `window:focus` 也会把隐藏的主界面拉回来。
- 改法：
  - 首页在 `pointerdown` 时同步加 `body.pre-hide`（opacity 0），不等 IPC 返回；恢复/失败/3 秒兜底时移除。
  - 收起时先 `setSkipTaskbar(true)` 再 `hide()`，恢复时先 `setSkipTaskbar(false)` 再 `show()/focus()`，任务栏按钮随主界面一起消失。
  - 启动兜底定时器在 `ready-to-show`/`closed` 时清除；`ready-to-show`、兜底定时器、`window:focus` 统一用 `homeHiddenForSession()` 守卫，框选/实时/音频进行中不再自动显示主界面。
- 打包版冷启动实测（点击→）：

| 场景 | pre-hide 类 | 主界面隐藏 | overlay 可见 | overlay 首帧 |
| --- | ---: | ---: | ---: | ---: |
| 截图翻译 | 13 ms | 9 ms | 242 ms | 292 ms |
| 实时字幕 | 11 ms | 6 ms | 191 ms | 207 ms |

- 三次冷启动范围：主界面隐藏 6–10 ms，截图 overlay 220–242 ms，实时 overlay 185–191 ms；每次 +1.8 s 与模拟 `window:focus` 后主界面都保持隐藏。

- 稳定性：截图 overlay 保持 1.8 s 后主界面仍隐藏；模拟悬停聚焦（`window:focus`）后仍隐藏；取消框选/停止实时后恢复可见且 `pre-hide` 清除。
- 最小化回归：用户原本最小化的主界面，框选期间与取消后都保持最小化（`iconic=true`），未被强行弹出。
