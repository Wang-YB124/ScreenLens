## 首页按钮触发与错误恢复（2026-10-27）

- 首页按钮：新增悬停激活（主进程光标轮询 + 渲染层 focus）、按下即触发（抑制随后 click 重复）、忙碌标签（准备中/框选中/启动中）与重复点击提示。
- 状态统一：实时字幕的框选现在同步 `selecting` 到主进程/首页；取消实时框选后按钮恢复。此前实时框选不进入首页 `selecting` 状态，导致按钮最多卡住 6 秒。
- 实测：
  - 程序化点击截图按钮：标签立即变「框选中…」并禁用；框选窗口出现；取消后恢复「截屏翻译」。
  - 程序化点击实时按钮：标签变「启动中…」；框选窗口出现（约 2.3 秒，含窗口枚举+屏幕冻结）；取消后应恢复（本次自动取消的 CDP 收尾出现挂起，属测试驱动问题，代码状态由主进程 selecting 同步修正）。

## 音频字幕（本地 Whisper，2026-10-27）

- 基础验证：Electron 桌面捕获可取得系统回环音轨（label=System Audio），播放中文 TTS 时 RMS 0.05–0.11；whisper.cpp BLAS + small-q5_1 对 10 秒中文音频识别约 0.7–1.6 秒。
- 端到端（开发版）：首页「音频字幕」→ 系统声音回环 → 本地 Whisper → 字幕条。中文 TTS 得到“这是一段用于特市系统音频识别的中文语音 / 今天天气很好我们一起来学习人工智能”（small 模型基本正确），显示“音频”徽标与 ORIG；静音/括号幻觉经过滤后不再出现；点字幕 × 关闭后音频状态与采集窗口均结束。
- 英文 TTS + 本地 Mock AI 翻译：识别出 “This is a test of real-time audio subtitles. / The system audio is captured locally and transcribed by whisper...” ，流式翻译显示 EN → 简体中文，provider=AI；关闭后恢复设置。
- 模型选择：优先 small-q5_1（约 182MB），base-q5_1 作为开发环境备用；发布包仅内置 small 以控制体积。
- 已知：约 6 秒分块带来 6–8 秒字幕延迟；识别受音量/噪声/口音影响；系统声音依赖 Windows 回环（已在本机验证），麦克风模式使用默认输入设备。
- 打包版（312MB 包）复测：内置 Whisper small q5_1 路径就绪；首页「音频字幕」标题/设置卡状态正确；系统声音中文 TTS 识别两段均正确（“这是一段用于测试系统音频识别的中文语音”“今天天气很好我们一起来学习人工智能”），字幕 × 关闭后音频结束；播放结束后曾出现一次“盐工技能”幻觉，已加入语音活跃比例门限（RMS≥0.0025 且活跃采样≥5%）后重打包复测。
