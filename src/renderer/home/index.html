数据如何流动

截图与 OCR 在本机完成，默认不离开电脑。只有你选中的文字会发送给翻译/模型服务；开启「多模态读图」后，选区截图也会发送给你配置的视觉模型。

历史截图、设置与 API Key 保存在本机；Key 使用 Windows 凭据加密。关闭免费通道且未配置模型时，翻译不可用。

第三方与许可

Windows OCR · 微软 Bing/MyMemory 免费翻译 · 你配置的 AI 服务 · Electron · KaTeX · highlight.js

第三方服务与隐私说明

免费翻译优先使用微软 Bing 翻译的公开网页接口，失败时回退 MyMemory；两者均受其额度与服务条款约束，商业发布前请自行评估。AI 翻译与解释由你配置的服务商处理，请查看对应服务商的隐私政策与计费规则。

OCR 使用 Windows 本地识别。截图默认不上传；只有开启多模态读图时，选区截图才会发送给视觉模型。API Key 使用 Windows 凭据加密保存在本机，不会显示在界面上。

Electron（MIT）、KaTeX（MIT）、highlight.js（BSD-3-Clause）等第三方组件及其许可证随发布包提供。AI 输出可能不准确，请在重要场景自行核对。
